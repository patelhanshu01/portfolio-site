HOW TO ADD YOUR IMAGES
======================
Drop image files into this folder using these exact names.
If a file is missing, the site automatically shows a gradient/emoji instead —
nothing breaks. JPG shown below, but .jpg/.jpeg/.png all work if you keep
the filename matching what's in the HTML (default expects .jpg).

YOUR PHOTO
  profile.jpg          → your headshot: About page portrait + round avatar in the nav
                         (portrait orientation works best, e.g. 800x1000)

PROJECT SCREENSHOTS (home page tile strip + Projects page cards)
  parksync.jpg         → ParkSync
  quantivyx.jpg        → Quantivyx AI
  libcolab.jpg         → LIBCOLAB
  supermario.jpg       → SuperMario
  chat.jpg             → MyChatApplication
  autorefresher.jpg    → AutoBrowserRefresher
  azure-cloud.jpg      → Azure Cloud Lab
  azure-ad.jpg         → Azure AD Lab
  osticket.jpg         → osTicket Helpdesk Lab

WIDE BANNERS (Featured page, optional — big header image on each case study)
  parksync-wide.jpg    → ParkSync banner (wide, e.g. 1600x600)
  quantivyx-wide.jpg   → Quantivyx AI banner

Tip: keep images under ~500 KB each for fast loading.
