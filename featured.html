ParkSync — Smart Parking Platform

A smart parking platform where users search and filter lots, view real-time availability, reserve and pay for spots, and track their CO₂ impact.

  • Responsive React + TypeScript front end with Google Maps geolocation and Three.js/WebXR 3D/AR parking layout visualization
  • Node.js/Express back end with PostgreSQL + TypeORM; Redis caching cut API latency by 30% and improved session load speeds
  • Stripe integration for secure payments and wallet credits; RESTful APIs with JWT-based authentication and role-based access control
  • Deployed in Docker containers with a GitHub Actions pipeline for automated testing and deployment

Quantivyx AI — Autonomous Wealth & Portfolio Management

An autonomous wealth management platform using predictive AI and market trend analysis to automate portfolio rebalancing and deliver real-time insights.

  • AI analytics service in Python (FastAPI) + Scikit-learn forecasting stock market movements and analyzing user spending patterns
  • Transaction engine in Java (Spring Boot) executing automated trades with ACID-compliant ledgers for high-volatility scenarios
  • Administrative dashboard in C# (.NET Core) with dependency injection and Razor Pages for high-performance reporting
  • Event-driven WebSocket pipeline ingesting live market data into PostgreSQL time-series records for historical analysis
  • Polyglot microservices orchestrated with Docker + Kubernetes, communicating via REST and GraphQL; CI/CD via GitHub Actions
